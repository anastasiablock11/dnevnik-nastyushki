# Дневник Настюшки

Личный мобильный календарь, дневник, трекер привычек и список покупок.

## Публикация через GitHub Pages

1. Откройте Settings -> Pages.
2. В Source выберите Deploy from a branch.
3. Выберите ветку main и папку /(root).
4. Нажмите Save.

После публикации сайт будет доступен по адресу:

`https://anastasiablock11.github.io/dnevnik-nastyushki/`

На первом этапе записи сохраняются только в браузере конкретного устройства. Облачная синхронизация и личный вход будут подключены следующим этапом через Supabase.
