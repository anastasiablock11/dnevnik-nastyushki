Что лучше сделать

SMTP пока не подключаем. Для личного дневника проще переделать вход на:

электронная почта + постоянный пароль

Тогда:

  • вход выполняется прямо внутри приложения на рабочем столе iPhone;

  • письмо и ссылка больше не нужны при каждом входе;

  • Safari не будет перехватывать авторизацию;

  • сессия сохранится именно внутри установленного приложения;

  • это остаётся бесплатно — Supabase поддерживает вход через signInWithPassword. Supabase

Сначала мы добавим на сайт кнопку «Создать пароль» для уже авторизованного аккаунта, затем форму «Почта + пароль» для входа из приложения.

Скачай из GitHub актуальный файл index.html, который сейчас опубликован на сайте, и загрузи его сюда. Я внесу изменения и верну готовый файл для замены на GitHub.

Что сделать

  1. На GitHub открой репозиторий дневника.

  2. Нажми Add file → Upload files.

  3. Загрузи новый index.html, согласившись заменить старый.

  4. Нажми Commit changes и дождись зелёной галочки публикации.

После обновления:

  1. Открой сайт именно в Safari, где ты сейчас уже авторизована.

  2. Перейди в Настройки → Облако и вход.

  3. Нажми «Создать или изменить пароль».

  4. Введи новый пароль два раза и сохрани.

Затем лучше удалить старую иконку дневника с рабочего стола iPhone и добавить сайт заново через Safari:

Поделиться → На экран «Домой».

В установленном приложении появится обычный вход:

  • электронная почта;

  • пароль;

  • кнопка «Войти».

Письма и переход в Safari после этого больше не понадобятся. Кнопка «Получить ссылку для первого входа» останется на случай, если пароль забудется или ещё не был создан.
